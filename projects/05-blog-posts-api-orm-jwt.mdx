## Phase 3 - Create Database ORM MOdels

### Objective

Define the structure of the `posts` table using a SQLAlchemy model.

### Database Design

### posts

| Column | Type | Constraints |
|---------|------|-------------|
| id | Integer | Primary Key |
| title | String(200) | Not Null |
| description | Text | Not Null |
| author | String(100) | Not Null |
| created_at | DateTime | Default Current Time |

### File Structure

```text
app/
│
├── database.py
└── models.py
```

### Step 1 - Create the schema

**File:** `app/models.py`

```python
from datetime import datetime

from sqlalchemy import DateTime, String, Text
from sqlalchemy.orm import Mapped, mapped_column

from app.database import Base


class Post(Base):
    __tablename__ = "posts"

    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str] = mapped_column(String(200))
    description: Mapped[str] = mapped_column(Text)
    author: Mapped[str] = mapped_column(String(100))
    created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow)
```

### Model Structure

```text

 │
 ├── id
 ├── title
 ├── description
 ├── author
 └── created_at
```

### How SQLAlchemy Maps the Model

```text

      │
      ▼
SQLAlchemy Model
      │
      ▼
Database Table
```

```text

      │
      ▼

```

```text
id            → INTEGER PRIMARY KEY
title         → VARCHAR(200)
description   → TEXT
author        → VARCHAR(100)
created_at    → DATETIME
```

### Summary

- `Base` is the parent class of every model.
- `__tablename__` specifies the table name.
- `Mapped[]` defines the Python data type.
- `mapped_column()` defines the database column.
- One model represents one database table.

### Complete File

**File:** `app/schemas.py`

```python
class PostBase(BaseModel):
    title: str
    description: str
    author: str


class PostRequest(PostBase):
    pass


class PostResponse(PostBase):
    id: int
    created_at: datetime

    model_config = ConfigDict(from_attributes=True)
```

### Model Hierarchy

```text
            BaseModel
                │
                ▼
            PostBase
          ┌──────────┐
          ▼          ▼
 PostRequest   PostResponse
                    │
              id
              created_at
```

### Why Use a Base Model?

Without `PostBase`, the fields would be duplicated.

```text
PostRequest
------------
title
description
author

PostResponse
-------------
title
description
author
id
created_at
```

With `PostBase`, the common fields are defined only once and inherited by both models.

### Key Points

- `PostBase` contains the common fields.
- `PostRequest` is used for creating and updating posts.
- `PostResponse` extends `PostBase` by adding database-generated fields.
- This approach avoids duplication and makes the models easier to maintain.

## Phase 7 - Repository Layer

### Objective

Implement the CRUD operations for the `posts` table using SQLAlchemy ORM.

### File Structure

```text
app/
│
├── crud.py
├── models.py
└── schemas.py
```

### Step 1 - Create a Post

**File:** `app/crud.py`

```python
from sqlalchemy.orm import Session

from app.schemas import PostRequest
from app.models import Post


def create_post(db: Session, post: PostRequest):
    db_post = Post(**post.model_dump())

    db.add(db_post)
    db.commit()
    db.refresh(db_post)

    return db_post
```

### Step 2 - Get All Posts

**File:** `app/crud.py`

```python
from sqlalchemy import select


def get_posts(db: Session):
    stmt = select(Post)

    return db.execute(stmt).scalars().all()
```

### Step 3 - Get a Post

**File:** `app/crud.py`

```python
def get_post(db: Session, post_id: int):
    stmt = select(Post).where(Post.id == post_id)

    return db.execute(stmt).scalar_one_or_none()
```

### Step 4 - Update a Post

**File:** `app/crud.py`

```python
def update_post(db: Session, post_id: int, post: PostRequest):
    db_post = get_post(db, post_id)

    if db_post:
        db_post.title = post.title
        db_post.description = post.description
        db_post.author = post.author

        db.commit()
        db.refresh(db_post)

    return db_post
```

### Step 5 - Delete a Post

**File:** `app/crud.py`

```python
def delete_post(db: Session, post_id: int):
    db_post = get_post(db, post_id)

    if db_post:
        db.delete(db_post)
        db.commit()

    return db_post
```

### Summary

```text
Create  → create_post()
Read    → get_posts()
Read    → get_post()
Update  → update_post()
Delete  → delete_post()
```

### Step 1 - Create the API Endpoints

**File:** `app/api/posts.py`

```python
from typing import Annotated

from fastapi import APIRouter, Depends
from sqlalchemy.orm import Session

from app.crud import (
    create_post,
    delete_post,
    get_post,
    get_posts,
    update_post,
)
from app.dependencies import get_db
from app.models import PostRequest, PostResponse

posts = APIRouter(prefix="/posts", tags=["Posts"])

DBSession = Annotated[Session, Depends(get_db)]


@router.post("/", response_model=PostResponse)
def create(post: PostRequest, db: DBSession):
    return create_post(db, post)


@router.get("/", response_model=list[PostResponse])
def read_all(db: DBSession):
    return get_posts(db)


@router.get("/{post_id}", response_model=PostResponse)
def read(post_id: int, db: DBSession):
    return get_post(db, post_id)


@router.put("/{post_id}", response_model=PostResponse)
def update(post_id: int, post: PostRequest, db: DBSession):
    return update_post(db, post_id, post)


@router.delete("/{post_id}", response_model=PostResponse)
def delete(post_id: int, db: DBSession):
    return delete_post(db, post_id)
```

### Step 2 - Register the Router

**File:** `app/main.py`

```python
from fastapi import FastAPI

from app.api.posts import posts

app = FastAPI()

app.include_router(posts)
```

### API Endpoints

| Method | Endpoint | Description |
|---------|----------|-------------|
| POST | `/posts` | Create a Post |
| GET | `/posts` | Get All Posts |
| GET | `/posts/{post_id}` | Get a Post |
| PUT | `/posts/{post_id}` | Update a Post |
| DELETE | `/posts/{post_id}` | Delete a Post |

### Request Flow

```text
Client
   │
   ▼
API Endpoint
   │
   ▼
Depends(get_db)
   │
   ▼
CRUD Layer
   │
   ▼
SQLAlchemy
   │
   ▼
SQLite
```

### Summary

- `APIRouter` groups all post-related endpoints.
- `Depends(get_db)` provides a database session.
- Endpoints call the CRUD functions.
- Pydantic models validate requests and responses.
