# Capstone Project - Student Management REST API

## Problem Statement

In this capstone project, you will build a **Student Management System** that exposes a set of RESTful APIs to manage student records.

The application should store student information in a **SQLite** database using **SQLAlchemy ORM** and follow a clean, modular architecture. Throughout this project, you will implement the application layer by layer, separating database operations, business logic, and API endpoints.

The application should support the following features:

- Add a Student
- View All Students
- Search Students using query parameters
- View Student Details
- Update Student Details
- Delete a Student

By the end of this project, you will have developed a complete backend application that demonstrates industry-standard practices for building REST APIs using FastAPI.

from sqlalchemy.orm import sessionmaker, DeclarativeBase

DATABASE_URL = "sqlite:///students.db"

engine = create_engine(
    DATABASE_URL,
    connect_args={"check_same_thread": False}

SessionLocal = sessionmaker(

    autocommit=False

# Step 8: Create the Pydantic Schemas

- **Age**
  - Required while creating a student.
  - Minimum value: **18**
  - Maximum value: **60**

- **Email**
  - Required while creating a student.
  - Must be a valid email address.

- **Update Schema**
  - All fields should be optional to support partial updates.

- **Response Schema**
  - Include the generated `id`.
  - Configure the schema to work with SQLAlchemy ORM objects.

Use **Annotated** and **Field** to implement the validations.

<Question>

Create the Pydantic schemas required for the Student Management System.

</Question>

<Accordion title="Solution">

```python
from typing import Annotated

from pydantic import BaseModel, ConfigDict, EmailStr, Field


class StudentCreate(BaseModel):
    name: Annotated[str, Field(min_length=3, max_length=50, description="Student name")]
    age: Annotated[int, Field(ge=18, le=60, description="Student age")]
    email: Annotated[EmailStr, Field(description="Student email address")]


class StudentUpdate(BaseModel):
    name: Annotated[str, Field(min_length=3, max_length=50, description="Student name")] | None = None
    age: Annotated[int, Field(ge=18, le=60, description="Student age")] | None = None
    email: Annotated[EmailStr, Field(description="Student email address")] | None = None


class StudentResponse(BaseModel):
    id: int
    name: str
    age: int
    email: EmailStr

    model_config = ConfigDict(from_attributes=True)
```

# Step 9: Implement the Repository Layer

## Objective

Implement the Repository Layer to perform all database operations.

The Repository Layer is responsible for interacting with the database. It contains only data access logic and should not contain any business rules or HTTP-specific logic.

In this project, the repository will implement all CRUD operations using SQLAlchemy ORM.

## Instructions

Create a `student_repository.py` file inside the `repositories` folder.

Implement the following methods:

- Create a student.
- Retrieve all students.
- Retrieve a student by ID.
- Retrieve a student by email.
- Search students using optional filters.
- Update an existing student.
- Delete a student.

The repository should:

- Use SQLAlchemy ORM.
- Use the modern `select()` API wherever applicable.
- Accept a database session as a parameter.
- Return SQLAlchemy ORM objects.
- Return `None` when a student is not found.
- Not perform input validation.
- Not implement business rules.
- Not raise `HTTPException` or `AppException`.
- Not depend on FastAPI.

<Question>

Implement the Student Repository using SQLAlchemy ORM.

</Question>

<Accordion title="Solution">

```python
from sqlalchemy import select
from sqlalchemy.orm import Session

from app.models.student import Student
from app.schemas.student import StudentCreate, StudentUpdate


class StudentRepository:

    def create(self, db: Session, student: StudentCreate) -> Student:
        db_student = Student(**student.model_dump())
        db.add(db_student)
        db.commit()
        db.refresh(db_student)
        return db_student

    def get_all(self, db: Session) -> list[Student]:
        return db.scalars(select(Student)).all()

    def get_by_id(self, db: Session, student_id: int) -> Student | None:
        return db.get(Student, student_id)

    def get_by_email(self, db: Session, email: str) -> Student | None:
        return db.scalar(select(Student).where(Student.email == email))

    def search(self, db: Session, name: str | None = None, min_age: int | None = None, max_age: int | None = None) -> list[Student]:
        stmt = select(Student)

        if name:
            stmt = stmt.where(Student.name.ilike(f"%{name}%"))

        if min_age:
            stmt = stmt.where(Student.age >= min_age)

        if max_age:
            stmt = stmt.where(Student.age <= max_age)

        return db.scalars(stmt).all()

    def update(self, db: Session, student: Student, data: StudentUpdate) -> Student:
        for key, value in data.model_dump(exclude_unset=True).items():
            setattr(student, key, value)

        db.commit()
        db.refresh(student)
        return student

    def delete(self, db: Session, student: Student) -> None:
        db.delete(student)
        db.commit()


student_repository = StudentRepository()
```

</Accordion>

# Step 11: Implement the Service Layer

## Objective

Implement the Service Layer to handle the business logic of the Student Management System.

The Service Layer acts as an intermediary between the API layer and the Repository Layer. It coordinates database operations, enforces business rules, and raises application exceptions whenever a business rule is violated.

## Instructions

Create a `student_service.py` file inside the `services` folder.

Implement the following methods:

- Create a student.
- Retrieve all students.
- Retrieve a student by ID.
- Search students.
- Update a student.
- Delete a student.

The service should:

- Use the Repository Layer for all database operations.
- Raise `AppException(404)` when a student is not found.
- Raise `AppException(409)` when an email address already exists.
- Return SQLAlchemy ORM objects.
- Not interact directly with FastAPI.
- Not execute SQLAlchemy queries directly.

<Question>

Implement the Student Service.

</Question>

<Accordion title="Solution">

```python
from sqlalchemy.orm import Session

from app.core.exceptions import AppException
from app.models.student import Student
from app.repositories.student_repository import student_repository
from app.schemas.student import StudentCreate, StudentUpdate


class StudentService:

    def create(self, db: Session, student: StudentCreate) -> Student:
        if student_repository.get_by_email(db, student.email):
            raise AppException(409, "Email already exists.")

        return student_repository.create(db, student)

    def get_all(self, db: Session) -> list[Student]:
        return student_repository.get_all(db)

    def get_by_id(self, db: Session, student_id: int) -> Student:
        student = student_repository.get_by_id(db, student_id)

        if student is None:
            raise AppException(404, "Student not found.")

        return student

    def search(self, db: Session, name: str | None = None, min_age: int | None = None, max_age: int | None = None) -> list[Student]:
        return student_repository.search(db, name, min_age, max_age)

    def update(self, db: Session, student_id: int, data: StudentUpdate) -> Student:
        student = self.get_by_id(db, student_id)

        if data.email:
            existing_student = student_repository.get_by_email(db, data.email)

            if existing_student and existing_student.id != student.id:
                raise AppException(409, "Email already exists.")

        return student_repository.update(db, student, data)

    def delete(self, db: Session, student_id: int) -> None:
        student = self.get_by_id(db, student_id)
        student_repository.delete(db, student)


student_service = StudentService()
```

</Accordion>

## Verify

Verify that:

- All CRUD methods have been implemented.
- The service uses only the Repository Layer for database operations.
- The service contains no SQLAlchemy queries.
- The service raises `AppException(404)` when a student is not found.
- The service raises `AppException(409)` when an email already exists.
- The service contains only business logic.
