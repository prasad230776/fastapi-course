# Complete Structure of the SELECT Statement

```sql
SELECT [DISTINCT] column1, column2, expression, ...
FROM table_name
[WHERE condition]
[GROUP BY column1, column2, ...]
[HAVING condition]
[ORDER BY column1 [ASC|DESC], column2 [ASC|DESC]]
[LIMIT number]
[OFFSET number];
```

## Clause Order

| Order | Clause | Purpose | Example |
|------:|--------|---------|---------|
| 1 | `SELECT` | Specifies the columns to retrieve | `SELECT employee_name, salary` |
| 2 | `DISTINCT` | Removes duplicate rows | `SELECT DISTINCT city` |
| 3 | `FROM` | Specifies the table | `FROM employee` |
| 4 | `WHERE` | Filters rows | `WHERE salary > 70000` |
| 5 | `GROUP BY` | Groups rows | `GROUP BY department_id` |
| 6 | `HAVING` | Filters grouped results | `HAVING AVG(salary) > 80000` |
| 7 | `ORDER BY` | Sorts the result | `ORDER BY salary DESC` |
| 8 | `LIMIT` | Restricts the number of rows | `LIMIT 5` |
| 9 | `OFFSET` | Skips rows | `OFFSET 5` |

# Complete Example

```sql
SELECT DISTINCT department_id,
       AVG(salary) AS average_salary
FROM employee
WHERE gender = 'Female'
GROUP BY department_id
HAVING AVG(salary) > 70000
ORDER BY average_salary DESC
LIMIT 3
OFFSET 1;
```

## Explanation

| Clause | Description |
|---------|-------------|
| `SELECT DISTINCT department_id, AVG(salary)` | Retrieves unique department IDs along with their average salary. |
| `FROM employee` | Reads data from the Employee table. |
| `WHERE gender = 'Female'` | Considers only female employees. |
| `GROUP BY department_id` | Creates one group for each department. |
| `HAVING AVG(salary) > 70000` | Keeps only departments whose average salary exceeds ₹70,000. |
| `ORDER BY average_salary DESC` | Sorts departments from highest to lowest average salary. |
| `LIMIT 3` | Returns only the first three rows. |
| `OFFSET 1` | Skips the first row before returning the results. |

# SQL Query Execution Order

Although we write the query in this order:

```sql
SELECT
FROM
WHERE
GROUP BY
HAVING
ORDER BY
LIMIT
OFFSET
```

The database processes it internally in the following order:

| Execution Order | Clause |
|---------------:|--------|
| 1 | `FROM` |
| 2 | `WHERE` |
| 3 | `GROUP BY` |
| 4 | `HAVING` |
| 5 | `SELECT` |
| 6 | `DISTINCT` |
| 7 | `ORDER BY` |
| 8 | `LIMIT` |
| 9 | `OFFSET` |

## Best Practices

- Use meaningful aliases.
- Always specify column names.
- Avoid SELECT * in production.
- Use WHERE with UPDATE and DELETE.
- Use indexes wisely.
- Keep queries readable.
- Write one clause per line.
- Prefer explicit JOIN syntax.
- Use transactions for critical operations.
- Comment complex queries.

## Filtering Data using WHERE

The `WHERE` clause filters rows based on one or more conditions.

### Syntax

```sql
SELECT column_name

```
## Comparison Operators

Comparison operators compare two values and return only the rows that satisfy the specified condition.

| Operator | Description | Example |
|----------|-------------|---------|
| `=` | Equal to | `department_id = 2` |

| `<` | Less than | `salary < 60000` |
| `>=` | Greater than or equal to | `salary >= 100000` |
| `<=` | Less than or equal to | `salary <= 70000` |

## Sorting Data using ORDER BY

The `ORDER BY` clause arranges the rows returned by a query in a specific order.

| Keyword | Description |
|---------|-------------|
| `ASC` | Sorts in ascending order (default) |
| `DESC` | Sorts in descending order |

## Ascending Order (`ASC`)

The `ASC` keyword sorts data from the smallest to the largest value. For text, it sorts alphabetically from A to Z. Since `ASC` is the default, it can be omitted.

Sort employees by salary in ascending order.

```sql
SELECT *
FROM employee
ORDER BY salary ASC;
```

The above query is equivalent to:

```sql
SELECT *
FROM employee
ORDER BY salary;
```

Sort employees alphabetically by name.

```sql
SELECT *
FROM employee
ORDER BY employee_name;
```

## Grouping Clauses

Grouping clauses work together with aggregate functions to summarize data and generate reports.

| Clause | Purpose |
|---------|---------|
| `GROUP BY` | Groups rows having the same value |
| `HAVING` | Filters groups after grouping |

## GROUP BY

The `GROUP BY` clause groups rows that have the same value in one or more columns.

It is commonly used with aggregate functions such as `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`.

Find the number of employees in each department.

```sql
SELECT department_id,
       COUNT(*) AS total_employees
FROM employee
GROUP BY department_id;
```

Find the average salary of each department.

```sql
SELECT department_id,
       AVG(salary) AS average_salary
FROM employee
GROUP BY department_id;
```

Find the highest salary in each department.

```sql
SELECT department_id,
       MAX(salary) AS highest_salary
FROM employee
GROUP BY department_id;
```

## HAVING

The `HAVING` clause filters the groups created by the `GROUP BY` clause.

Unlike the `WHERE` clause, which filters individual rows, `HAVING` filters the grouped results.

Display departments having more than four employees.

```sql
SELECT department_id,
       COUNT(*) AS total_employees
FROM employee
GROUP BY department_id
HAVING COUNT(*) > 4;
```

Display departments whose average salary is greater than ₹80,000.

```sql
SELECT department_id,
       AVG(salary) AS average_salary
FROM employee
GROUP BY department_id
HAVING AVG(salary) > 80000;
```

Display cities having more than two employees.

```sql
SELECT city,
       COUNT(*) AS total_employees
FROM employee
GROUP BY city
HAVING COUNT(*) > 2;
```

## WHERE vs HAVING

Both `WHERE` and `HAVING` are used to filter data, but they operate at different stages of query execution.

| WHERE | HAVING |
|--------|---------|
| Filters individual rows | Filters grouped rows |
| Applied before `GROUP BY` | Applied after `GROUP BY` |
| Cannot use aggregate functions | Can use aggregate functions |

### Example using WHERE

Display employees earning more than ₹80,000.

```sql
SELECT *
FROM employee
WHERE salary > 80000;
```

### Example using HAVING

Display departments whose average salary is greater than ₹80,000.

```sql
SELECT department_id,
       AVG(salary) AS average_salary
FROM employee
GROUP BY department_id
HAVING AVG(salary) > 80000;
```
