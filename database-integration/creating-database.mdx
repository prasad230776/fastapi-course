# Working with the Employee Management Database

Before learning SQL, we'll work with a sample database that represents an **Employee Management System**.

Instead of creating tables from scratch, we'll import a ready-made database and use it to learn SQL through practical examples.

## Project Database

Throughout this course, we'll use a database named:

```text
employee_management.db
```

The database contains two related tables:

- Department
- Employee

## Database Design

### Department

| Column | Description |
|---------|-------------|
| department_id | Unique identifier for the department |
| department_name | Name of the department |

### Employee

| Column | Description |
|---------|-------------|
| employee_id | Unique identifier for the employee |
| employee_name | Employee name |
| gender | Gender of the employee |
| designation | Employee job title |
| email | Employee email address |
| salary | Monthly salary (₹) |
| department_id | Department to which the employee belongs |
| city | Employee's work location |
| joining_date | Date the employee joined the company |

## Sample Database Script

Create a file named:

```text
employee_management.sql
```

Paste the following SQL script into the file.

```sql
DROP TABLE IF EXISTS employee;
DROP TABLE IF EXISTS department;

CREATE TABLE department (
    department_id INTEGER PRIMARY KEY,
    department_name TEXT NOT NULL
);

CREATE TABLE employee (
    employee_id INTEGER PRIMARY KEY,
    employee_name TEXT NOT NULL,
    gender TEXT NOT NULL,
    designation TEXT NOT NULL,
    email TEXT UNIQUE,
    salary REAL NOT NULL,
    department_id INTEGER NOT NULL,
    city TEXT NOT NULL,
    joining_date TEXT NOT NULL,
    FOREIGN KEY (department_id) REFERENCES department(department_id)
);

## Importing the Database

1. Open the project folder in Visual Studio Code.
2. Create a new SQLite database named:

```text
employee_management.db
```

3. Open the database using the **SQLite** extension.
4. Open the `employee_management.sql` file.
5. Execute the SQL script.

The database, tables, and sample data will be created automatically.

## Exploring the Database

Open the **SQLite Explorer** in Visual Studio Code.

You can:

- View the database
- Expand the tables
- Inspect table columns
- Browse table data
- Refresh the explorer after changes

You should now see the following tables:

- Department
- Employee

## Viewing Table Data

Select a table from the SQLite Explorer to view its contents.

You can:

- Browse records
- Sort records
- Search records
- Verify changes after executing SQL statements

## Writing SQL Queries

Create a file named:

```text
queries.sql
```

We'll write all SQL queries in this file throughout the course.

## Running Your First Query

Write the following query:

```sql
SELECT *
FROM employee;
```

Execute the query using the **Run Query** option provided by the SQLite extension.

The results will be displayed in the **Query Results** window.

## Course Workflow

Throughout this course, we'll follow the same workflow:

1. Open the database
2. Explore the tables
3. Write SQL queries in `queries.sql`
4. Execute the queries
5. View the results
6. Modify the queries
7. Observe the output

In the next module, we'll begin learning SQL by writing our first **SELECT** statements to retrieve data from the Employee and Department tables.
