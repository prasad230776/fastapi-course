# Introduction to Databases

Almost every software application stores and manages data. Whether you're building a banking system, an e-commerce platform, a social media application, or an AI-powered application, you need a reliable way to store, organize, and retrieve information. This is where **databases** come in.

A **database** is an organized collection of data that allows you to efficiently store, retrieve, update, and manage information.

Instead of storing data in text files or spreadsheets, databases provide a structured, secure, and efficient way to manage large amounts of data while supporting multiple users and applications.

## Why Do We Need Databases?

Databases help us to:

- Store large amounts of data efficiently
- Retrieve data quickly
- Insert, update, and delete records easily
- Reduce duplicate data
- Maintain data consistency
- Support multiple users simultaneously
- Improve security and reliability
- Backup and recover data when needed

## Types of Databases

Databases are broadly classified into two categories.

### Relational Databases (SQL)

Relational databases organize data into **tables** consisting of **rows** and **columns**. Tables can be connected using relationships, making it easy to store and retrieve related information.

**Examples**

- SQLite
- MySQL
- PostgreSQL
- Microsoft SQL Server
- Oracle Database

### NoSQL Databases

NoSQL databases store data in formats other than tables, making them suitable for handling large volumes of unstructured or semi-structured data.

**Examples**

- MongoDB (Document)
- Redis (Key-Value)
- Cassandra (Column Family)
- Neo4j (Graph)

## SQL vs NoSQL

| SQL | NoSQL |
|------|--------|
| Relational database | Non-relational database |
| Stores data in tables | Stores data as documents, key-value pairs, graphs, etc. |
| Fixed schema | Flexible schema |
| Uses SQL | Uses database-specific query languages |
| Best for structured data | Best for unstructured or rapidly changing data |

> In this course, we'll focus on **Relational Databases** and **SQL**.

# Introduction to SQL

**SQL (Structured Query Language)** is the standard language used to communicate with relational databases. Instead of interacting with the database directly, we write SQL statements that tell the database what we want to do.

SQL allows us to:

- Create databases and tables
- Store new data
- Retrieve specific information
- Update existing records
- Delete records
- Combine data from multiple tables
- Analyze and summarize data
- Manage database structure

Unlike programming languages such as Python or Java, SQL is a **declarative language**. This means you specify **what** data you want, and the database determines **how** to retrieve it efficiently.

## Why Learn SQL?

SQL is one of the most important skills for software developers because almost every modern application relies on a database.

SQL is commonly used to:

- Build backend applications
- Develop REST APIs
- Create dashboards and reports
- Analyze business data
- Manage application data
- Work with ORMs like SQLAlchemy
- Build applications using FastAPI, Django, Spring Boot, .NET, Laravel, and many other frameworks
