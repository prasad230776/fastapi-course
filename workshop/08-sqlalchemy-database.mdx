## 1. Engine & Session Setup

Configure the database engine and session factory to talk to SQLite databases.

```python
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker, declarative_base

SQLALCHEMY_DATABASE_URL = "sqlite:///./app.db"

# Connect to SQLite (disable same_thread check for testing threads)
engine = create_engine(
    SQLALCHEMY_DATABASE_URL, connect_args={"check_same_thread": False}
)

SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)

Base = declarative_base()
```

## 2. Declarative Base Models

Map Python classes directly to database tables.

```python
from sqlalchemy import Column, Integer, String, Boolean
from sqlalchemy.orm import relationship
from .database import Base

class DbUser(Base):
    __tablename__ = "users"

    id = Column(Integer, primary_key=True, index=True)
    username = Column(String, unique=True, index=True, nullable=False)
    email = Column(String, unique=True, index=True, nullable=False)
    is_active = Column(Boolean, default=True)
```

## 3. Database Session Dependency

Inject context-managed database sessions into FastAPI paths, ensuring connections close when execution completes.

```python
from fastapi import Depends
from sqlalchemy.orm import Session
from .database import SessionLocal

# Database session yield generator
def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

## 4. Transaction Operations (CRUD)

Run transactional commands inside sessions safely.

```python
from sqlalchemy.orm import Session
from .models import DbUser

# 1. Create (Insert)
def create_user(db: Session, username: str, email: str):
    new_user = DbUser(username=username, email=email)
    db.add(new_user)
    db.commit()      # Commit transaction
    db.refresh(new_user)  # Refresh instance with generated ID
    return new_user

# 2. Read (Query)
def get_user_by_username(db: Session, username: str):
    return db.query(DbUser).filter(DbUser.username == username).first()
```

### Exercise 2: Safe Stock Update API
Write a function `deduct_stock(db: Session, product_id: int, quantity: int) -> bool` that decreases product stock. If the remaining stock falls below zero, roll back the transaction and return `False`.

<Accordion title="Click to view solution">
```python
from sqlalchemy.orm import Session
from .models import DbProduct

def deduct_stock(db: Session, product_id: int, quantity: int) -> bool:
    product = db.query(DbProduct).filter(DbProduct.id == product_id).first()
    if not product:
        return False
    
    try:
        product.stock_count -= quantity
        if product.stock_count < 0:
            raise ValueError("Insufficient stock count.")
        db.commit()
        return True
    except Exception:
        db.rollback()  # Undo modifications
        return False
```
