## 1. Dependency Injection (DI) Concepts

Dependency Injection is a design pattern where an object receives its dependencies from an external assembler, rather than creating them internally. This decouples classes and aids unit testing.

```python
class Logger:
    def log(self, message: str):
        print(f"[LOG]: {message}")

# Without DI (Tightly Coupled)
class BadService:
    def __init__(self):
        self.logger = Logger()  # Hardcoded dependency

# With DI (Decoupled)
class GoodService:
    def __init__(self, logger: Logger):
        self.logger = logger  # Injected dependency
```

## 2. Dependency Management with `uv`

`uv` is an extremely fast Python package installer and resolver designed as a replacement for standard `pip` and `poetry`.

### Basic Commands
```bash
# Create a virtual environment
uv venv

# Activate the virtual environment
source .venv/bin/activate

# Install packages
uv pip install fastapi uvicorn

# Generate lockfile
uv pip compile pyproject.toml -o requirements.txt
```

## 3. Environment Variables and Configuration

Keep secrets (like API tokens and database keys) out of codebase commits. Use `dotenv` to load values dynamically from a `.env` file.

### `.env` File
```env
API_SECRET_KEY="secret-12345"
DATABASE_URL="sqlite:///./test.db"
```

### Python Code
```python
import os
from dotenv import load_dotenv

# Load env variables
load_dotenv()

secret = os.getenv("API_SECRET_KEY")
print(f"Loaded secret: {secret}")
```

## 4. Consuming REST APIs in Python

Utilize the asynchronous HTTP client library `httpx` (or standard `requests`) to request data from external APIs.

```python
import httpx
import asyncio

async def fetch_github_user(username: str):
    url = f"https://api.github.com/users/{username}"
    async with httpx.AsyncClient() as client:
        response = await client.get(url)
        if response.status_code == 200:
            data = response.json()
            print(f"Name: {data.get('name')}, Public Repos: {data.get('public_repos')}")
        else:
            print("Failed to fetch user.")

# Running async task
# asyncio.run(fetch_github_user("fastapi"))
```

### Exercise 2: Mock External Weather API Client
Write an asynchronous function `fetch_weather(city: str) -> dict` that hits `https://httpbin.org/json` to emulate calling a real weather API. Read the target API URL from a `.env` config file.

<Accordion title="Click to view solution">
```python
import os
import httpx
from dotenv import load_dotenv

load_dotenv()

async def fetch_weather(city: str) -> dict:
    base_url = os.getenv("WEATHER_API_URL", "https://httpbin.org/anything")
    params = {"q": city, "units": "metric"}
    
    async with httpx.AsyncClient() as client:
        response = await client.get(base_url, params=params)
        response.raise_for_status()
        return response.json()
```
