# Python Comprehensions

Comprehensions provide a Pythonic way to create and transform collections with less code. They improve readability, reduce boilerplate code, and are often faster than traditional loops.

# Why Comprehensions?

Suppose we want to create a list containing the squares of numbers from `1` to `5`.

A common approach is to use a `for` loop.

```python
squares = []

for number in range(1, 6):
    squares.append(number ** 2)

print(squares)
```

<Accordion title="Show Output">

```text
[1, 4, 9, 16, 25]
```

</Accordion>

Although this works well, it requires multiple lines of code.

Python provides **comprehensions** to perform the same task in a cleaner and more concise way.

```python
squares = [number ** 2 for number in range(1, 6)]

print(squares)
```

<Accordion title="Show Output">

```text
[1, 4, 9, 16, 25]
```

</Accordion>

## Benefits of Comprehensions

- Write less code.
- Improve readability.
- Avoid unnecessary temporary variables.
- Often perform better than traditional loops.
- Express data transformations more clearly.


## General Syntax

```python
[expression for item in iterable]
```

Where:

- **expression** → Value to be added to the collection.
- **item** → Current element from the iterable.
- **iterable** → Any iterable object such as a string, list, tuple, range, dictionary, or set.

# List Comprehensions

A **list comprehension** creates a new list by applying an expression to each element of an iterable.

## Basic List Comprehension

Traditional approach

```python
numbers = []

for number in range(1, 6):
    numbers.append(number)

print(numbers)
```

<Accordion title="Show Output">

```text
[1, 2, 3, 4, 5]
```

</Accordion>

Using a list comprehension

```python
numbers = [number for number in range(1, 6)]

print(numbers)
```

<Accordion title="Show Output">

```text
[1, 2, 3, 4, 5]
```

</Accordion>


## Transforming Values

Each element can be modified before adding it to the list.

```python
squares = [number ** 2 for number in range(1, 6)]

print(squares)
```

<Accordion title="Show Output">

```text
[1, 4, 9, 16, 25]
```

</Accordion>

Another example.

```python
text = "python"

uppercase = [character.upper() for character in text]

print(uppercase)
```

<Accordion title="Show Output">

```text
['P', 'Y', 'T', 'H', 'O', 'N']
```

</Accordion>


## Using Conditions

A comprehension can filter elements using an `if` condition.

Traditional approach

```python
even_numbers = []

for number in range(1, 11):
    if number % 2 == 0:
        even_numbers.append(number)

print(even_numbers)
```

<Accordion title="Show Output">

```text
[2, 4, 6, 8, 10]
```

</Accordion>

Using a comprehension

```python
even_numbers = [
    number
    for number in range(1, 11)
    if number % 2 == 0
]

print(even_numbers)
```

<Accordion title="Show Output">

```text
[2, 4, 6, 8, 10]
```

</Accordion>


## Using Conditional Expressions

Python also allows `if...else` expressions inside comprehensions.

```python
result = [
    "Even" if number % 2 == 0 else "Odd"
    for number in range(1, 6)
]

print(result)
```

<Accordion title="Show Output">

```text
['Odd', 'Even', 'Odd', 'Even', 'Odd']
```

</Accordion>

Notice the difference.

Filtering

```python
[number for number in range(10) if number % 2 == 0]
```

Conditional expression

```python
["Even" if number % 2 == 0 else "Odd" for number in range(10)]
```

The first **filters** elements.

The second **transforms** every element.


## Multiple `for` Clauses

A list comprehension can contain more than one `for` loop.

Traditional approach

```python
pairs = []

for x in range(1, 4):
    for y in range(1, 3):
        pairs.append((x, y))

print(pairs)
```

<Accordion title="Show Output">

```text
[(1, 1), (1, 2), (2, 1), (2, 2), (3, 1), (3, 2)]
```

</Accordion>

Using a comprehension

```python
pairs = [
    (x, y)
    for x in range(1, 4)
    for y in range(1, 3)
]

print(pairs)
```

<Accordion title="Show Output">

```text
[(1, 1), (1, 2), (2, 1), (2, 2), (3, 1), (3, 2)]
```

</Accordion>

# Dictionary Comprehensions

A **dictionary comprehension** provides a concise way to create dictionaries.

Instead of creating an empty dictionary and adding key-value pairs one by one, a dictionary comprehension creates the entire dictionary in a single expression.


## Basic Dictionary Comprehension

Traditional approach

```python
squares = {}

for number in range(1, 6):
    squares[number] = number ** 2

print(squares)
```

<Accordion title="Show Output">

```text
{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

</Accordion>

Using a dictionary comprehension

```python
squares = {
    number: number ** 2
    for number in range(1, 6)
}

print(squares)
```

<Accordion title="Show Output">

```text
{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

</Accordion>


## Using Conditions

Dictionary comprehensions can also filter elements.

Traditional approach

```python
squares = {}

for number in range(1, 11):
    if number % 2 == 0:
        squares[number] = number ** 2

print(squares)
```

<Accordion title="Show Output">

```text
{2: 4, 4: 16, 6: 36, 8: 64, 10: 100}
```

</Accordion>

Using a comprehension

```python
squares = {
    number: number ** 2
    for number in range(1, 11)
    if number % 2 == 0
}

print(squares)
```

<Accordion title="Show Output">

```text
{2: 4, 4: 16, 6: 36, 8: 64, 10: 100}
```

</Accordion>


## Transforming an Existing Dictionary

Dictionary comprehensions can transform values.

```python
marks = {
    "Alice": 80,
    "Bob": 65,
    "Charlie": 90
}

updated_marks = {
    name: mark + 5
    for name, mark in marks.items()
}

print(updated_marks)
```

<Accordion title="Show Output">

```text
{'Alice': 85, 'Bob': 70, 'Charlie': 95}
```

</Accordion>


## Inverting Keys and Values

```python
grades = {
    "Alice": "A",
    "Bob": "B",
    "Charlie": "A"
}

result = {
    grade: name
    for name, grade in grades.items()
}

print(result)
```

<Accordion title="Show Output">

```text
{'A': 'Charlie', 'B': 'Bob'}
```

</Accordion>

> **Note:** If duplicate values exist in the original dictionary, later keys overwrite earlier ones.

# Set Comprehensions

A **set comprehension** creates a set in a concise and readable manner.

Since sets store **unique values**, duplicate elements are automatically removed.


## Basic Set Comprehension

Traditional approach

```python
numbers = [1, 2, 2, 3, 4, 4, 5]

unique = set()

for number in numbers:
    unique.add(number)

print(unique)
```

<Accordion title="Show Output">

```text
{1, 2, 3, 4, 5}
```

</Accordion>

Using a set comprehension

```python
numbers = [1, 2, 2, 3, 4, 4, 5]

unique = {
    number
    for number in numbers
}

print(unique)
```

<Accordion title="Show Output">

```text
{1, 2, 3, 4, 5}
```

</Accordion>


## Transforming Values

```python
squares = {
    number ** 2
    for number in range(1, 6)
}

print(squares)
```

<Accordion title="Show Output">

```text
{1, 4, 9, 16, 25}
```

</Accordion>

# Iterators

Before learning generator expressions, it's important to understand **iterators**.

An **iterator** is an object that returns one item at a time from a collection.

Python automatically uses iterators whenever you loop over a collection using a `for` loop.

```python
numbers = [10, 20, 30]

for number in numbers:
    print(number)
```

<Accordion title="Show Output">

```text
10
20
30
```

</Accordion>

Behind the scenes, Python creates an iterator for the list.


## Creating an Iterator

The `iter()` function creates an iterator from an iterable.

```python
numbers = [10, 20, 30]

iterator = iter(numbers)

print(iterator)
```

<Accordion title="Show Output">

```text
<list_iterator object at ...>
```

</Accordion>


## Getting Values Using `next()`

The `next()` function retrieves one value at a time.

```python
numbers = [10, 20, 30]

iterator = iter(numbers)

print(next(iterator))
print(next(iterator))
print(next(iterator))
```

<Accordion title="Show Output">

```text
10
20
30
```

</Accordion>

After all elements are consumed, another call to `next()` raises a `StopIteration` exception.

```python
numbers = [10]

iterator = iter(numbers)

print(next(iterator))

print(next(iterator))
```

<Accordion title="Show Output">

```text
10

StopIteration
```

</Accordion>


## Why Iterators?

Iterators process one element at a time instead of processing the entire collection at once.

Many Python objects such as lists, tuples, strings, dictionaries, sets, files, and generator expressions are iterable.

Understanding iterators makes it easier to understand **generator expressions**.

# Generator Expressions

A **generator expression** is similar to a list comprehension, but instead of creating an entire list, it generates values **one at a time**.

This makes generator expressions more memory efficient, especially when working with large datasets.


## List Comprehension

```python
squares = [
    number ** 2
    for number in range(1, 6)
]

print(squares)
```

<Accordion title="Show Output">

```text
[1, 4, 9, 16, 25]
```

</Accordion>

The entire list is created and stored in memory.


## Generator Expression

Replace square brackets (`[]`) with parentheses (`()`).

```python
squares = (
    number ** 2
    for number in range(1, 6)
)

print(squares)
```

<Accordion title="Show Output">

```text
<generator object ...>
```

</Accordion>

The values are **not** generated immediately.


## Iterating Over a Generator

```python
squares = (
    number ** 2
    for number in range(1, 6)
)

for value in squares:
    print(value)
```

<Accordion title="Show Output">

```text
1
4
9
16
25
```

</Accordion>

The values are produced only when required.


## Using `next()`

Since a generator is also an iterator, `next()` can be used.

```python
squares = (
    number ** 2
    for number in range(1, 6)
)

print(next(squares))
print(next(squares))
print(next(squares))
```

<Accordion title="Show Output">

```text
1
4
9
```

</Accordion>

Each call generates the next value.


## List Comprehensions vs Generator Expressions

| Feature | List Comprehension | Generator Expression |
|----------|--------------------|----------------------|
| Syntax | `[]` | `()` |
| Stores all values | ✅ Yes | ❌ No |
| Memory Usage | Higher | Lower |
| Evaluation | Immediate | Lazy |
| Best For | Small to medium collections | Large datasets |


## When Should You Use a Generator Expression?

Use a generator expression when:

- Working with large datasets.
- Processing values one at a time.
- Memory efficiency is important.

Use a list comprehension when:

- You need all values immediately.
- The collection will be reused multiple times.
- Fast random access is required.

# Comprehensions vs Traditional Loops

Both loops and comprehensions can solve the same problems, but each has its own strengths.

| Feature | Traditional Loop | Comprehension |
|---------|------------------|---------------|
| Readability | Better for complex logic | Better for simple transformations |
| Code Length | More lines | Fewer lines |
| Performance | Good | Often slightly faster |
| Best Use | Complex processing | Creating and transforming collections |

## Best Practices

- Use comprehensions for **simple transformations**.
- Avoid deeply nested comprehensions.
- Prefer readability over writing one-liners.
- Use generator expressions when processing large datasets.
- When the logic becomes complex, use a normal loop.
