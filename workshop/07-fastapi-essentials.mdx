## 2. Request Handling and Parameters

* **Path Parameters**: Extract IDs directly from URLs.
* **Query Parameters**: Capture key-value queries for filtering.
* **Request Body**: Automatically validate JSON payloads using Pydantic models.

```python
from fastapi import FastAPI, Query
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    price: float

@app.post("/items/{item_id}")
async def create_item(
    item_id: int, 
    item: Item, 
    discount: float = Query(0.0, ge=0.0, le=1.0)
):
    final_price = item.price * (1.0 - discount)
    return {
        "item_id": item_id,
        "name": item.name,
        "original_price": item.price,
        "discounted_price": final_price
    }
```

## 3. Dependency Injection (DI) in FastAPI

FastAPI implements a powerful Dependency Injection system using `Depends()`.

```python
from fastapi import FastAPI, Depends, Header, HTTPException

app = FastAPI()

# 1. Define Dependency function
async def verify_token(x_token: str = Header(...)):
    if x_token != "supersecrettoken":
        raise HTTPException(status_code=400, detail="Invalid X-Token header.")
    return x_token

# 2. Inject dependency into route
@app.get("/secure-data")
async def get_secure_data(token: str = Depends(verify_token)):
    return {"data": "Protected details", "token_used": token}
```

### Exercise 1: Task Tracker Endpoints
Define a simple task schema with a Pydantic model (`title: str`, `completed: bool = False`). Write a POST endpoint `/tasks` that validates the input and returns it with a generated ID, and a GET endpoint `/tasks` that accepts a query parameter `completed: bool = None` to filter results.

<Accordion title="Click to view solution">
```python
from fastapi import FastAPI, Query
from pydantic import BaseModel
from typing import List, Optional

app = FastAPI()

class Task(BaseModel):
    title: str
    completed: bool = False

db = []

@app.post("/tasks", status_code=201)
async def create_task(task: Task):
    new_id = len(db) + 1
    task_data = {"id": new_id, **task.model_dump()}
    db.append(task_data)
    return task_data

@app.get("/tasks")
async def read_tasks(completed: Optional[bool] = Query(None)):
    if completed is not None:
        return [t for t in db if t["completed"] == completed]
    return db
```

### Exercise 2: User Authorization Dependency
Create a dependency `verify_user_level(user_level: str = Header(...))` that throws an HTTP 403 Forbidden exception if the header value does not equal `"admin"`. Bind this dependency to a secure route.

<Accordion title="Click to view solution">
```python
from fastapi import FastAPI, Depends, Header, HTTPException, status

app = FastAPI()

async def verify_user_level(user_level: str = Header(...)):
    if user_level != "admin":
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Access forbidden: Admin clearance required."
        )
    return user_level

@app.get("/admin/dashboard")
async def admin_dashboard(level: str = Depends(verify_user_level)):
    return {"message": f"Welcome to the control room. Level: {level}"}
```
