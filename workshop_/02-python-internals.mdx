## 1. Mutability and References

Every variable in Python holds a reference to an object in memory.
* **Mutable objects** (lists, dicts, sets) can be altered in place.
* **Immutable objects** (ints, floats, strings, tuples) cannot be altered. Modifying them creates a new object in memory.

```python
# Mutable side effect example
def append_to(element, target=[]):  # Dangerous default value!
    target.append(element)
    return target

print(append_to(1))  # [1]
print(append_to(2))  # [1, 2] -- The default list persists in memory!
```

## 2. Scoping and the LEGB Rule

Python resolves names using four nested scopes:
1. **L**ocal: Names assigned within a function.
2. **E**nclosing: Names in local scope of enclosing functions (nonlocal).
3. **G**lobal: Names assigned at the top-level of a module.
4. **B**uilt-in: Names preassigned by Python (e.g., `open`, `range`).

```python
x = "global"

def outer():
    x = "enclosing"
    def inner():
        nonlocal x
        x = "modified enclosing"
    inner()
    print(x)  # Prints: "modified enclosing"

outer()
```

## 3. Closures

A **closure** is a nested function that retains access to variables from its enclosing scope even after the outer function has finished executing.

```python
def make_multiplier(factor: int):
    def multiply(number: int) -> int:
        return number * factor
    return multiply

double = make_multiplier(2)
print(double(5))  # 10
```

## 4. Decorators

Decorators dynamically wrap another function to extend its behavior without editing the source code.

```python
import functools
import time

def timer_decorator(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        duration = time.perf_counter() - start
        print(f"{func.__name__} executed in {duration:.4f}s")
        return result
    return wrapper

@timer_decorator
def process():
    time.sleep(0.5)

process()
```

## 5. Context Managers

Context managers clean up system resources (like file streams or database connections) using the `with` statement.

```python
from contextlib import contextmanager

# 1. Class-based Context Manager
class FileOpener:
    def __init__(self, filename, mode):
        self.filename = filename
        self.mode = mode

    def __enter__(self):
        self.file = open(self.filename, self.mode)
        return self.file

    def __exit__(self, exc_type, exc_val, exc_tb):
        self.file.close()

# 2. Generator-based Context Manager
@contextmanager
def db_session():
    print("Connecting to Database...")
    try:
        yield "DB_CONNECTION_OBJECT"
    finally:
        print("Closing Database Connection.")
```

### Exercise 2: Authorization Decorator
Write a decorator `@require_role(role: str)` that checks a global variable `current_user_role` and raises a `PermissionError` if the user's role does not match the required role.

<Accordion title="Click to view solution">
```python
import functools

current_user_role = "guest"

def require_role(role: str):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            if current_user_role != role:
                raise PermissionError(f"Access Denied: Requires {role} role.")
            return func(*args, **kwargs)
        return wrapper
    return decorator

# Usage:
# @require_role("admin")
# def delete_system():
#     print("System deleted.")
```
